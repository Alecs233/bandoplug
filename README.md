## 🚀 Cum se hostează pe Vercel (Gratuit & Rapid)

### Metoda 1: Direct cu GitHub & Vercel (Recomandat)
1. Intră pe [github.com](https://github.com) și creează un repository nou numit `bandoplug`.
2. Încarcă fișierele din acest folder (`index.html`, `style.css`, `app.js`, `vercel.json`, folderul `assets/`).
3. Intră pe [vercel.com](https://vercel.com) și loghează-te (poți folosi contul de GitHub).
4. Apasă pe **Add New...** -> **Project**.
5. Selectează repository-ul `bandoplug` și apasă pe **Deploy**.
6. În 10 secunde site-ul va fi live cu link gratuit de tipul `bandoplug.vercel.app` (sau îi poți pune domeniu propriu).

### Metoda 2: Vercel CLI (din Terminal)
Dacă ai Node.js instalat:
```bash
npm i -g vercel
vercel
```
Urmează pașii din terminal și site-ul va fi publicat instant!
